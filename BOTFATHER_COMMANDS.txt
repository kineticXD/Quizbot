# BOTFATHER COMMAND SETUP — unified Bot API bot
# 1. Open Telegram and message @BotFather
# 2. Send /setcommands and select the single Quizbot/Shikimori bot
# 3. Paste the commands below

start - Start bot or open a quiz
skip - Skip the current quiz question
pause - Pause a running quiz
resume - Resume a paused quiz
stop - Stop a running quiz
slow - Slow down the quiz timer
fast - Speed up the quiz timer
normal - Restore the normal timer
timer - Set exact per-question timer
leaderboard - Show a quiz leaderboard
help - Show all commands
features - Show bot features
create - Create a quiz
done - Save the current quiz draft
cancel - Cancel an active creator session
sourcequiz - Create a quiz from source material
sourcequizcancel - Cancel source-to-quiz mode
myquizzes - List your quizzes
info - Show quiz information
edit - Edit an existing quiz
stopedit - Close the quiz editor
del - Delete one of your quizzes
search - Search public quizzes
setpromo - Set a promo message on your quizzes
settings - Manage creator settings
remove - Add words to your import filter
mywords - List filtered words
clearlist - Clear filtered words
setkey - Save an AI provider key
mykeys - List saved AI provider keys
delkey - Delete an AI provider key
add - Authorize a chat for paid quizzes
rem - Remove a paid-quiz chat authorization
remall - Clear paid-quiz chat authorizations
pay - View premium plans
auth - Grant premium access (owner/admin)
removeuser - Revoke premium access (owner/admin)
batch - List your quiz batches
createbatch - Create a quiz batch
searchbatch - Search public batches
whtml - Export quiz as HTML report
testseries - Generate a test-series PDF
leaders - Show a quiz leaderboard
aspirants - Alias for leaders
pollquiz - Publish a timed poll quiz
quizpoll - Alias for pollquiz
publish - Alias for pollquiz
pollsettings - Configure timed poll defaults
polltarget - Choose the forum topic for polls
pollstop - Stop a timed poll quiz
pollclose - Close published polls without results
pollfinish - Close polls and publish leaderboard
mystats - View your quiz statistics
mistakes - Review your recent quiz mistakes
schedule - Schedule a quiz or timed poll
viewschedule - View scheduled quizzes
myschedules - View your schedules
cancelschedule - Cancel a scheduled quiz
aiquiz - Generate a quiz from a topic
pdfquiz - Generate a quiz from a PDF
mix - Combine existing quizzes
html - Toggle HTML reports
pdf - Toggle PDF reports
trans - Translate quiz questions
creatorstatus - Show creator migration status

# Owner/admin commands
statses - Show platform statistics
testapi - Test database connectivity
limit - Show current creator command limits
gcast - Broadcast a replied-to message
stopcast - Stop an active broadcast
listquiz - List quizzes in the configured group
ban - Ban a quiz creator and remove their quizzes
convertall - Convert all paid quizzes to free
delall - Delete every quiz (confirmation required)
